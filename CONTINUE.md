The plate is finished and verified. It is not correct in the way a specialist
would call correct, and this file says exactly where the soft parts are.

Hand the block below to a coding agent, or read the ranked list yourself and
pick one.

```text
You are picking up a finished, verified project: a reference plate holding all
218 non-special ISO 15924 scripts as a descent tree, with all 8,587 Glottolog
languages beneath the script that writes them.

Start by reading, in this order: README.md, then PROMPT.md (the original brief
plus a KNOWN TRAPS section that will save you a day), then CONTINUE.md, then
genealogy.py.

Then rebuild and confirm the baseline before changing anything:

  pip install fonttools uharfbuzz brotli
  python fetch.py && python fetch_wikidata.py && python fonts.py
  python build_data.py && python render.py && python verify.py

verify.py must print ALL CHECKS PASS and exit 0. If it does not, fix that
first and report what drifted upstream. New ISO 15924 codes and new Glottolog
releases both land a few times a year, and both are supposed to make the
checks fail rather than pass quietly.

Then take ONE item from the ranked list in CONTINUE.md. Do not take several.
Each one changes what the plate asserts, and they need to be reviewable
separately.

Rules that are not negotiable on this project:

- Every number on the plate is computed from a source file and asserted in
  verify.py. If you add a claim, add its check. After the check passes, break
  the thing it checks and confirm it goes red. A check that cannot fail is
  not a check.
- Never draw a glyph you did not pull from a font and shape with HarfBuzz. A
  script with no font gets a marked gap, never a lookalike.
- Never relabel "no script recorded" as "unwritten". The distinction is the
  most honest thing on the plate and it is easy to erode in a caption.
- Keep the edge-strength tags. If you cannot source a descent claim, mark it
  contested rather than promoting it to attested.
- Report what you actually observed. If you changed genealogy.py, say which
  rows and on what authority.

Settled, do not reopen without a reason:
- The pyramid silhouette was traded for a tidy tree on purpose. Centring each
  depth band severs a node from its parent and the descent lines become
  untraceable sweeps.
- Descent is curated by hand, not scraped. Wikidata P144 covers about half the
  registry and contradicts itself on the Semitic chain.
- Zsye (Emoji) stays on the plate, typed as a symbol set, because the scope
  removes only the six named Z codes and a silent edit is worse.
```

## Open work, ranked

### Done: the descent claims (was items 1 and 2)

Worked through on 2026-10-22 against the Unicode encoding proposals, the core
specification and peer-reviewed work; every source is named row by row in the
`SOURCES` table of `genealogy.py`, and check 9 fails the build if a descent
edge has none.

What moved, and why:

- **A new edge kind, `invented`.** Eighteen scripts, mostly twentieth-century,
  are described by their own proposals as having no genetic relationship with
  any script (Mro, Tangsa, Pau Cin Hau, Ol Chiki, Toto, Chisoi, Afaka, Beria
  Erfe, Shavian, Visible Speech, SignWriting...). They had been drawn as
  Latin's children with a stimulus edge. They are now `invented`, hung under
  the script their makers already wrote, and the legend says that position is
  a placement, not a descent.
- **Stimulus edges with a real model.** Garay and Osmanya from Arabic (letter
  order, direction), Pollard Miao from Cree syllabics, Nag Mundari from Ol
  Chiki, Bassa Vah from Vai, Nyiakeng Puachue Hmong from Hebrew letter shapes,
  Ugaritic from the Levantine linear alphabet rather than from cuneiform,
  Sora Sompeng, Masaram Gondi and Gurung Khema from the Brahmi model, Khitan
  small from Uyghur, Proto-Elamite from proto-cuneiform.
- **Attested edges that were not.** Glagolitic (origin of the shapes
  unsolved), Thaana (letters from numerals), Hanifi Rohingya, Duployan, Old
  Permic, Kayah Li, Tirhuta and Kaithi (siblings of Bengali and Devanagari
  through Gaudi and Nagari, not their children), Makasar (closest to Rejang,
  no evolutionary tie to Buginese), Tai Viet (from Sukhothai, not Tai Tham).
- **Contested, with both sides named.** Tifinagh now hangs from Phoenician,
  the majority view, instead of South Arabian. Sidetic from Phoenician in
  parallel with Greek. Manichaean, Yezidi, Mahajani, Saurashtra, Baybayin,
  Bamum, Kirat Rai, Gunjala Gondi, Leke, Tai Yo and Vithkuqi are contested,
  and so are Hanunoo, Buhid and Tagbanwa, which Unicode says may not descend
  from Baybayin at all (they were also dated 1300 with no source; now 1600).
  The eleven contested edges of the first version were each checked and kept.
- **Dates that were wrong.** New Tai Lue 1200 to 1955, Toto 1936 to 2015,
  Tolong Siki 1980 to 1988, Gurung Khema 1980 to 1995, Kirat Rai 1990 to 1925,
  Beria Erfe 1980 to 1950 and its direction from right-to-left to
  left-to-right, Leke 1830 to 1844, Baybayin 1300 to 1550, Yi 1300 to 1485.

A second pass, the same day, audited the 99 edges left `attested`, so every
descent claim now has a source and check 9 covers them all. It moved:

- **Pallava.** Grantha had been standing in for the Pallava script, but
  Grantha was designed around 600 (Francis 2024) and Pallava is older. Khmer,
  Cham, Kawi, Burmese and Tamil now hang from Brahmi through Pallava as
  sisters of Grantha, not its daughters. This also cleared Cham (400) being
  older than its parent.
- **Kadamba.** Kannada and Telugu are named as sisters through Kadamba.
- **Lao** from Thai through Fakkham (Lorrillard), not from Khmer. **Ranjana**
  from the Newar script (Pandey), not from Siddham. **Mandaic** from
  Elymaic, contested (Iranica).
- **Newly contested:** Samaritan (a 4th-c. CE creation, Barag), Old South
  Arabian (Proto-Canaanite or Phoenician-type, Sass), Marchen, Limbu, Naxi
  Geba, Old Sundanese, Batak, Buginese.
- **First attestations that were origin guesses:** Samaritan -600 to 350,
  Arabic 400 to 512 (Zabad; Namara and Jabal Ramm are Nabataean script), Nushu
  1400 to 1850, Kharosthi -400 to -250, Old Sogdian -100 to 313, Mongolian
  1204 to 1224, Ge'ez -100 to 200, hieratic -3200 to -2700, cuneiform proper
  -2900 to -2600, Meroitic -300 to -150 and -220, Greek -800 to -750, Latin
  -700 to -600, Cyrillic 900 to 921, Mkhedruli 1000 to 982, Devanagari 700 to
  851, Siddham 550 to 588, Modi 1200 to 1600, Gurmukhi 1539 to 1570 (1539 was
  a guruship date), Newar 1100 to 908, Lao 1350 to 1494, Thai 1283 to 1292
  (the Ram Khamhaeng inscription, authenticity disputed), Burmese 1000 to
  1113, Tai Tham 1300 to 1376, Tai Le 1300 to 1407, Rejang 1700 to 1750, Batak
  1300 to 1764, Balinese 1000 to 914, Avestan now 500 to the present (still
  liturgical; first manuscript 1288).

Still soft, and named so it can be argued with:

- `Saur` Saurashtra has no source for any parent; its row says so.
- Sixteen `invented` scripts sit under Latin, most because no source names
  the literacy their makers came from. For Toto, Mro and Chisoi a regional script
  (Bengali, Burmese) is at least as likely. The edge kind already says the
  position is not a descent; a source per script would make it a fact.
- Three children are dated before their parent: Avestan (500, a creation
  estimate) before Book Pahlavi (619, first dated papyri), Syloti Nagri (1500)
  before Kaithi (1550), Makasar (1600) before Rejang (1750). Start is first
  attestation, and a parent's earliest documents can be lost, so this is not
  an error by itself.
- Vai: Latin, Arabic and Cherokee stimuli are all proposed and none
  established. It stays under Latin, flagged in its source note.
- Canadian Aboriginal syllabics: the much repeated Devanagari model has no
  source beyond Evans knowing the script (Nichols 1996). It stays under Latin
  through British shorthand.

### 2. A specialist pass on the contested roots

Brahmi governs the placement of about 60 scripts and its Aramaic origin is the
majority view, not a settled one. Hangul's Phags-pa link covers five or six
consonant shapes at most. Egyptian independence from Sumer is the majority
view. Each is recorded; none has been reviewed by someone who works on it.

### 3. Done in part: language to script coverage, 17.7% to 52.6%

SIL's langtags.json (MIT, kept with the Ethnologue script editor) is now a
third source. Written: 4,517 of 8,587 (52.6%), 3,000 of them on langtags
alone. Listed as unwritten: 2,856. No record either way: 1,214. Before it was
added, its agreement with Wikidata and CLDR was measured: at least one shared
script for 1,294 of the 1,330 languages all three cover. Tagsets flagged
unwritten never contribute a script (langtags documents regional inference on
them). Multi-script languages now hang under a ranked primary script
(langtags default tag, then CLDR primary, then Wikidata); 4 of 723 still fall
back to alphabetical order. Members of a macrolanguage (Mandarin, Malay) have
their default tagset filed under the macrolanguage in langtags, which left
them only special tagsets; they were briefly drawn under Braille, and check 12
now fails if Braille is ever the main script of a language that has another.

Still open:

- 3,000 languages rest on langtags alone, which inherits the Ethnologue's
  judgement. A second independent source per language would make them firmer.
  ScriptSource (scriptsource.org) is the next candidate; Wikipedia infoboxes
  after that.
- The unwritten flag is positive evidence but not proof: a listed language can
  have a missionary or school orthography that langtags has not caught.
- Of the 1,214 with no record, 754 have no ISO 639-3 code, which every
  script source keys on; bridging Glottocodes to scripts directly would reach
  them. Another 218 are sign languages, which langtags tags `Zxxx` (no
  script) rather than unwritten. They could take a field of their own, with
  SignWriting as the one script that writes some of them.

### 4. Done: monthly rebuild and drift check

`.github/workflows/monthly.yml` runs the whole pipeline from live sources on
the 3rd of each month and fails on any of three things: a new ISO 15924 code
(build_data.py stops on a script with no genealogy row), a broken acceptance
check (verify.py), or a figure that moved against the committed dataset
(`drift.py`). `drift.py` was seen to fail against the August build, naming
the four figures that had moved since (one more language without a script,
five more with a speaker count, and the root list). When it fails, rebuild
locally, read the drift, update the README figures, and commit the new
`out/`. The workflow has not yet run on GitHub: the first scheduled run, or a
manual dispatch, is its real test.

### 5. Seven specimens are recoverable

`Gara` `Gukh` `Krai` `Onao` `Sunu` `Todr` `Tutg` are encoded in Unicode 16 and
have no Noto face yet. Re-running `fonts.py` will pick them up as Noto ships
them, taking the specimen count from 179 to 186. The other 32 gaps are scripts
Unicode has never encoded, so no font for them can exist and they stay gaps.

### 6. The two recursions are not equal

Script descent is a full tree. Language descent is reduced to a sort key inside
each field. Script and genealogy are orthogonal (Latin script covers French,
Vietnamese, Turkish and Indonesian, which share no ancestor), and the plate
currently only shows one of them properly.

Drawing both trees facing each other, linked by chords, is denser and more
honest. It is also a different plate, so it may deserve to be a second output
rather than a change to this one.

### 7. The SVG is not usable in a browser

26,248 pixels wide. Browsers will open it, but nobody can navigate it, and the
6,000-wide PNG makes every card illegible. A deep-zoom viewer with tiles, or a
simple pan-and-zoom page with the SVG inline, would make the artefact actually
readable by people who are not going to download 1.7 MB and open Inkscape.

The SVG already carries an id on every node, so a viewer can link to a single
script.

### 8. Smaller, real, unglamorous

- Only 111 of 218 scripts have a native name. Wikidata P1705 is thin.
- Speaker counts reach 19.8% of languages. Unknown counts still draw at the
  smallest size; the caption now says so with the computed share, but a
  distinct encoding would be more honest than a caption.

Done on 2026-10-22: the 350 languages with no endangerment status in
Glottolog draw as a dashed ring instead of the faintest fill, which read as
"nearly extinct"; the plate has a `<title>`, a `<desc>` and a title on every
script card, asserted by check 10.

## What a good change looks like

One item. A commit that says which rows moved and on what authority. A check in
`verify.py` that would have caught the old state. A note in the README if the
headline numbers moved.
